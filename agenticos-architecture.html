Why This Wins · Defensible Moats

Four compounding moats. Each amplifies the others.

01
Local-First Privacy

In a market sprinting toward "send everything to the cloud", AgenticOS keeps your data on disk by default. The only AI OS a lawyer, doctor, or solo founder can adopt without an audit.

02
Provider Agnostic

10 model providers, one interface. When OpenAI hikes prices or Anthropic deprecates a model, you swap in one click. Customers never get held hostage.

03
Skill Marketplace

Like VS Code Extensions but for agentic workflows. Each verified skill is a tiny, sandboxed product. Network effect compounds — every new skill makes the platform more valuable.

04
Safety as Feature

5-tier permission ladder + crypto audit + dry-run defaults. The only agent system that won't go rogue. Enterprise will pay a premium for this guarantee.

End-to-End Setup

From npm install to a billing-enabled production deployment. Green tags = shipped this session.

01
Bootstrap DONE

npm install then npm run dev at http://localhost:3000. vault/, .agenticos/, .agenticos-project/ auto-create. Vault ships with .obsidian/ config so Obsidian recognises it instantly.

02
Swap sql.js → better-sqlite3

npm uninstall sql.js @types/sql.js then npm install better-sqlite3. Rewrite lib/db/client.ts with persistent file handle, PRAGMA journal_mode=WAL, drop manual saveDb().

03
LLM adapters DONE

Anthropic / OpenAI / Gemini / Grok / OpenRouter / Ollama / NVIDIA wired via fetch with usage capture. Set ANTHROPIC_API_KEY / OPENAI_API_KEY / GEMINI_API_KEY / GROK_API_KEY / OPENROUTER_API_KEY / NVIDIA_API_KEY in env to enable.

04
Real vector memory

npm install vectordb. Replace embeddingPlaceholder in lib/memory/indexer.ts with Ollama nomic-embed-text. Store vectors in a Lance table; query with .search().

05
Permission + execution-mode fixes DONE

Both fixed and unit-test ready. Add tests/policy.test.ts next.

06
SSE streaming DONE

app/api/runs/[id]/stream/route.ts emits status, step, final, error, timeout events. UI can subscribe with new EventSource('/api/runs/<id>/stream').

07
Real scheduler DONE

node-cron boots from app/layout.tsx via startScheduler(). Natural-language parser recognises "every day at 09:00", "weekdays", "Monday/Friday". POST /api/scheduler to reload.

08
Real integrations

GitHub (octokit), Gmail (Google OAuth + Gmail API), Calendar. Each adapter gets read/draft/write. Update integration.status to connected when creds present.

09
Cost meter DONE

lib/billing/pricing.ts ships a per-model pricing table. Engine multiplies usage × price → runs.cost_estimate. Cost also lands in vault frontmatter.

10
Auth

Install lucia or better-auth. Single-user passkey for v1. Protect every /api/* except /api/auth/*. Encrypt provider API keys with keytar.

11
Tests + CI

npm install -D vitest @playwright/test. Add tests/policy.test.ts, tests/engine.test.ts, tests/repositories.test.ts, e2e/run-flow.spec.ts. GitHub Actions: typecheck → lint → vitest → playwright on every PR.

12
MCP bridge DONE

lib/mcp/bridge.ts speaks JSON-RPC over stdio. POST /api/mcp with { id, command, args } to connect. GET lists discovered tools with auto-classified risk.

13
Multi-agent swarm DONE

lib/agent/swarm.ts runs Researcher → Writer → Critic → Editor. Triggered by skill swarm-cascade or useSwarm: true in run request.

14
Run replay + diff UI

Add app/runs/[id]/replay/page.tsx with editable prompt + side-by-side diff via react-diff-viewer.

15
Mobile + voice

Spin up Expo app in /mobile. QR-pair with desktop. Push via Expo. whisper.cpp + piper behind /api/voice/*.

16
Encrypted vault sync

Each device generates an age keypair. Vault diffs zstd-compressed, age-encrypted, uploaded to a user-configured S3 / R2.

17
Skill marketplace

Manifest = signed JSON in agenticos/skills registry. Install verifies signature, drops into data/installed-skills/. Sandboxed per permission manifest.

18
Landing + billing

Static landing → Stripe Checkout for Pro / Teams. Self-host stays free. Cloud sync + scheduler on Fly.io. Waitlist via Resend + Supabase.

19
SOC-2 prep

Vanta / Drata onboarding. Sign every audit log entry with an Ed25519 key. Document the 5-tier permission model. Run built-in /security-review skill.

20
Launch

Open-source the core. Pro / Teams gated by license check. Show HN + Product Hunt + IndieHackers same week. Discord. 3 case studies. Apply YC W26.

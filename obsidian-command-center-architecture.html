Vault Structure · The Memory Layer

The vault is the truth. Three flows: raw/ is the human inbox, wiki/ is the LLM-curated knowledge base, output/ is artifact storage. Everything is git-versioned plain markdown.

vault/
_archive-vault/ # cold storage
raw/ # inbox — dump anything
karpathy-tweet.md
article-about-rag.md
random-paper.pdf
daily-notes/ # YYYY-MM-DD.md
inbox/ # triage queue
content/ # scripts, drafts
projects/ # {project}-project.md
ops/ # schedule, tasks
wiki/ # LLM-curated
_master-index.md
ai-agents/
rag-systems/
content-creation/
system/ # prompts, templates
output/ # run artifacts
query-results.md
slide-decks/
CLAUDE.md # persistent agent context

RAW — Human Inbox

Anything goes. Tweets, papers, half-thoughts, voice transcripts. No structure required. Agent processes nightly.

WIKI — Curated Memory

LLM-maintained knowledge base. Topic-organized. Cross-linked. The agent promotes raw/ ideas here after multiple references.

DAILY — Reflection Log

One file per day with templated sections. Schedule, tasks, journal. Source of truth for weekly review.

PROJECTS — Reusable Context

One markdown per active project. Pass into any new session to skip re-explanation. Lives forever.

OUTPUT — Generated Artifacts

Where runs save deliverables: research reports, content drafts, slide decks, briefs. Never edit raw; treat as build artifacts.

CLAUDE.md — Agent Instructions

The constitution. Tone, taboos, project rules, default behaviors. Loaded into every session automatically.

08

Why This Wins

Most AI productivity tools fight context. This stack is context.

01
Memory You Can See
Opaque chat memory is a black box. Markdown files are inspectable, editable, diff-able. You always know what the agent knows.
02
Compounds With Time
Every note makes the next session smarter. The vault is a personal model fine-tune you write by hand.
03
Portable Forever
It's a folder of .md files. Switch tools, switch models, switch decades. The corpus survives every vendor.
04
Approval-Gated By Default
No silent sends, no surprise charges. The agent proposes; you commit. Dry-run is a feature, not a flag.
